- App Store version **1.15.1** selects successful build **54**.
- Build is enabled for `ticklr-testers`, the pre-existing internal group.
- Current release policy is **AFTER_APPROVAL**; it was preserved.
- Mac distribution was enabled despite the guide's intended opt-out. After
  account-holder sign-in, **Make this app available** under Apple Silicon Mac
  Availability was unchecked and saved in ASC. A page reload confirmed the

  authenticated browser was required. Public compatibility text can lag the
  saved availability decision; it is not the source of truth for this setting.

  the public page after Apple approves before posting the joint “out now”
  announcement. Google Play 1.15.1 is already live.

## F-Droid: deferred by user

The user deferred F-Droid distribution on 19 October 2026. The following
findings are preserved for later work and do not block this App Store / Google
Play release. No F-Droid release or maintainer follow-up is being pursued.

The runbook previously claimed Ticklr was already in F-Droid. Public package
and fdroiddata metadata lookups return 404. The actual
[initial MR !45665](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/45665)
was **closed for inactivity on 18 October**, not merged. The maintainer permits
reopening. Its earlier reproducible-build pipeline passed for **1.12.3 (134)**,
not 1.15.1.

The 18 September device review still needs answers:

1. Android Compose accepts one recipient, while the listing claims several.
   Current released source and English listing still disagree. Correct the
   translated listing claim or implement and test multi-recipient composition.
2. App Light theme on an Android Dark system leaves status-bar icons unreadable.
   Current source sets edge-to-edge once without observing the selected app
   theme. Fix and verify both override directions in a future native release.

TIC-101 (Backlog) and `docs/fdroid/README.md` now record these findings and the eventual
sequence: resolve them, update the existing GitLab source branch to a released
full commit hash, rerun F-Droid CI/device testing, reopen the MR, and obtain
maintainer acceptance/indexing. A production tag cannot finish this initial
submission. No maintainer message or reopening was sent while the findings
remain unresolved. Fixing native Android behavior requires a later version;
the published 1.15.1 artifacts and tags must stay immutable.
